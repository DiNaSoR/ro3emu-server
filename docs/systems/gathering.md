- `data/sceneeditor/sc_moc_fild12_001_sceneeditor.json` group 1371 links 23 authored `m_kWorldMonsterSpawnPoints` (including point 312) to RefreshInfo 10522201. `data/config/RefreshInfo.json` selects NPC 7010001 with weight 10000, target 15, minimum 10, refresh parameter 2. - NPCConfig 7010001 is type 2/subtype 12 with `_iSubTypeValue=100100`, shared limit `_iCTimes[0]=1`, no personal limit and `_iInterval=0`. NPCInteractConfig 70100001 uses status 5 and condition 7000079 (active miner level 1). The client `LC_Unit_Collection.lua:442-582,874-907` reads `collection_info` maps and persisted 5010 map/point counts; its cooldown is epoch seconds. `LC_State_Unit_Interact.lua:152-219,583-661` reads the 32702 collection cast deadline in milliseconds and distinguishes interrupted versus completed Idle.
- **Inferred:** authored point ID is `point_config_id`; active points are chosen in ascending ID order; RefreshInfo `_iRefreshTime=2` is treated as seconds after depletion; each consumed point schedules a replacement, or the group is filled to target if below minimum. The source does not prove the original selection/randomization or reset timing. Current miner nodes have no per-player limit or interval; per-player counts are persisted without a guessed reset rule. `collection_info` includes a zero-key entry in each map so the client's direct table index is safe when no real player-specific entry exists.
- **Inferred:** `_iPlayParam=[3100101,4500,1]` supplies the base 4500 ms cast, adjusted by the selected life-job speed effect; successful completion sends a terminal 32702 Idle with `Interrupt=false`, and interruption sends `true`. `_iGameplay` entries are treated as `(weight, game ID, ...)` and a 33516 request only settles a selected positive configured game ID; all eight exported LifeCollectionConfig rows have zero game IDs. For a configured game, the earliest accepted report is `PublicParamConfig.LifeJobGameCountdown` (3 seconds) plus `LifeGameConfig._iDuration` (20 or 8 seconds), with five seconds of report latency. The reported rating selects the configured `LifeGamePlayAward` extra count after this server timing/identity check. The score behind that rating is not server-observable, so rating authenticity remains unverified.
- A committed yield sends 31322 GetRewardNotify with ManifestType Drop (8), the node position and its NPC id, like a monster kill. The client's only path to ground loot is that notice (`LC_DAL_Reward` -> `LC_TipHelper.PopRewardTip` -> `_popDropItemTip` -> `LC_DroppedItemManager:RegistLocal` with `NPCConfig._iDropPlanID`; Ore Vein and Plant rows use plan 1), so the yield scatters at the node and flies to the player. The items are already in the bag; Base/Job EXP rows are not dropped.
- **Inferred:** interaction uses three-dimensional distance with 1.5 units of position tolerance beyond the NPC's configured distance; movement over 0.1 units cancels a cast. A request to use another skill cancels gathering even when that skill is refused.
