# Skill growth implementation

`SkillService` owns AUTO_SYNC 5025 and requests 31151, 31152, 31153, 31156, 31157, 31159 and 31160. The durable `role.skill_plans` blob stores the selected zero-based index and each plan's levels, manual/auto positions, selected load levels, queue, name and genre. `RoleProgress.Skills` and `RoleProgress.SkillBar` remain the selected plan's projection for combat and quest consumers. A plan mutation saves the blob and the active projection in one SQLite transaction. `Learned` runs after an active allocation, reset or plan switch so subscribers can refresh derived effects.

The client contract is `MG_SkillGrowth.proto:36-143`. `SkillTreeConfig._iJob/_iX1..7` and the career's `_kSkillReplace` define the available groups. `SkillConfig._iMaxLevel`, `_iInitialLevel`, `_iActivateCondition` and the **desired level row's** `_kPreSkillRequired` define limits, free levels and dependencies. `JobLvConfig._iSkillPoint` grants separate rank pools. 31151 applies all target levels to a copy and validates the resulting graph and rank pools before saving, so removing a prerequisite requires the dependent refund in the same request. Zero is allowed for unlearned skills where the configured initial level is zero. 5025 includes every available group with explicit zero levels, remaining rank points and the selected plan's wheel. The normal attack uses its configured row and stays outside the six ordinary skill buttons.

**Normal attack by weapon.** The normal attack (5025 `currentAtkSkillId` / `skillWheel.atkSkillId`, which the client attacks with) follows `JobAttackConfig` the way the client's `Lua_CFG_JobAttackConfig.GetNormalSkillID` reads it: key = main hand `ItemConfig._iSubType` × 10 + dual wield (both hands the same subtype; the off hand's subtype when the main hand is empty, 0 bare-handed), then the job's any-weapon row (empty `_kWeaponType`), then `JobConfig._kSkillNormalID`. So a Thief with a Dagger attacks with 1005001 "Basic Attack" (ATK × 50% + 45), with two Daggers 1005201, with a Katar 1005101, and otherwise 1500001 "Normal Attack" (ATK × 50%); a Swordman with 1001001 and a Knight or Crusader with 1001101 (`JobConfig` names 1100001 / 1140001 for them). Every group a career's rows name counts as learned at level 1, and an equip, unequip or equipment plan switch resends 5025. The skill window draws the Novice tree's Normal Attack cell as this attack (`UI_Sys_Skill_AddBitWidgetBaseCtrl` swaps the Novice attack's group for `GetNormalSkillID`'s), which is why the server must report its group learned; a bar slot holding the Novice attack or another of the career's normal attacks casts the current one past Novice. Battle-mount rows (`_iMountID`) are not applied yet (**inferred** to stay on the unmounted row).

**Double Attack** (Thief 15002): with a Dagger in the main hand, any normal attack (`_iIsNormalAtk` 1) has the level row's `_kDescData[0]`% chance (1% per level) to add `_kDescData[1]` hit(s) of PATK × `_kDescData[2]`% (50%) Neutral physical damage after defense and element, folded into the same hit with `SkillHitInfo.split` raised so it shows as extra numbers, the way `_kShowDmg` splits multi-hit skills (**inferred**: the client has no separate packet for it). The Katar CRIT half is not applied.

**Passive skills that change other skills (inferred link).** A passive skill level row (`SkillConfig._iBasicType` 0) usually has a `BuffConfig` row with the same id (`_iBuffID` = the skill group, `_iLevel` = the skill level; 703 of the export's 1,042 passive rows). Its `_kSkillAttributeList` is the passive's effect on other skills: Fatal Blow 1100301 `[0,11001,29,5,500]` raises Bash's percentage damage multiplier by 5%, Signum Crucis switches Holy Light to its mode-2 row, Graffiti Mastery switches Cross Ripper Slasher to mode 1. While the level is learned, `CombatService.PassiveSkills` adds these tuples to `SkillParameterRules` as non-buff modifiers (no buff instance or icon), so casts and 31132 see them; they follow learning, plan switch, reset and job change. Excluded: Wolf Taming (mounted only), Advanced Katar Mastery (its +85% crit, type 10, is not applied, so only the -20% half would land) and the stack monitors 11317/11318. Steel Crow 13105 has no rows of its own, and its Blitz Beat +1%/level sits under Beastbane's group 13104 (rows 1310401-1310410, named Steel Crow), so Steel Crow reads those rows by level and Beastbane reads none; Beastbane keeps its Brute/Insect damage % from `_kAttri` (inferred client id swap). These rows' `_kChangeAttri` are mostly stale (Riding's Holy damage reduction, Emergency Treatment's PATK), so a passive's stats stay its `SkillConfig._kAttri`; only Meditatio, Mana Recharge and Create Deadly Poison add their buff attributes, which match their descriptions. **Weapon, shield and mount conditions.** A passive level row's `_iSpecialEffect` names SpecialEffectConfig tuples: `[16, weapon subtype, attr, value]` applies while the main hand holds that ItemConfig subtype (Sword Mastery 2/3, Spear Mastery 4/5, Sword Quicken, Mace Mastery 8, Axe Mastery 6/7/8, Double Attack's Katar CRIT 12, Dual-Wield Mastery's Dagger ASPD/AGI 1), `[17, mount type, attr, value]` while riding a Battle mount of that CartRemouldTable `_iSubType` (Riding +5% move speed on Peco 2, dragon 6, gryphon 7; Dragon Training on the dragon), and `[21, weapon subtype, ...]` adds a skill change while that weapon is held (Mace Mastery). Monster Resistance 11421/11508/11637 cut monster hits by their `_kDescData` 30/40/50% while an off-hand shield (subtype 50) is held; the best one applies (inferred: they do not stack). With a two-handed spear (subtype 5, Knight Spear; Halberd 4 is one-handed), Holy Cross uses its second damage entry and Divine Insight grants only 1162405 (otherwise 1162305). Aspersio's buff makes normal attacks Holy (from its description; its `_kLogicData` [4, 4701] is not decoded). Skill weapon requirements (`_iSkillCondition`) are still left to the client. Modifier types the rules do not apply yet (crit 10, buff duration 33/34) are carried but ignored; Mana Recharge's SP cost cut arrives through its per_sp_dedution attribute (skill-protocol.md).

**Procs and follow-up skills** (`CombatService.Procs`). A follow-up is a server-started cast of a SkillConfig row at a target: it runs through the same effect code as a cast (damage, kill, `_kBuff2`, 31101), sends an extra-skill timeline (31121) so the client can show it beside the current action (inferred), costs nothing, starts no cooldown and rolls no further procs or extra hits (Double Attack, cards). A damaging follow-up always hits enemies, because some name their trigger's self-cast visual (Death Bound's 11381 selects the caster). Chance procs roll once per cast on its main target (the requested one, else the first hit; inferred), with BuffConfig `_kLogicData` read as [chance bp, row, ...]: Envenom 15111's buff (group 15120) on normal attacks, which also turns them Poison ("Basic Attack becomes Poison-property"); Deadly Poison 15211 on any damaging hit (inferred from "after attacking"); Fear Breeze 13303's buff [3000] on a single-target skill other than the normal attack with a bow (ItemConfig subtype 11), casting Fear Breeze 13304 of the buff's level; Double Holy Light 14311 after Judex 14309, two independent rolls that Holy Spirit Surge 14312's buff sets to its [10000]; and Warg Strike 13312's auto-learned trigger 13317 (`_kAutoLearnSkill`) on Focused Arrow Strike 13305, at most once per the Warg Strike row's `_kDescData[6]` seconds (2.5). Envenom and Virus Spread add their own `_kLogicData` row (Poisoned 1511601-1511610) on the target. Lex Aeterna's 1216 -2000 counts in the damage (the 12xx copies of the damage stats are now their own factors, see skills-rest.md) and the buff (`_kBuffScript` Buff_Lex_Aeterna) is removed by the hit it raised. Answers to a monster's melee hit (a swing, or a skill without `_iDistanceType` 2): Parry 11210 casts its Auto Counter row at the attacker after a Physical hit, once per the skill's `_kDescData[2]` seconds; Death Bound 11311 deals the buff's `_kDescData[2]`% of the damage taken to enemies in the row's area, once per `_kDescData[3]` seconds; Auto Counter 11105 counters when its 1 s parry ends, in the row's front box, +`_kDescData[3]`% (50%) if a melee Physical hit landed during it. Not yet: Venom Splasher's expiry hit, Soul Drain's on-kill SP, Energy Coat, the talent "Trigger Effect" buffs, card procs, and Warg Strike's mounted form.

**Damage formulas, multi-part hits and target shapes** (`CombatService.Formulas`). `_kDamageFormulaExtra` multiplies a player's hit (inferred from the descriptions; the client only shows the terms): `T_AXadd0_etc` [1, A, attribute, 1] = 1 + A x attribute / 10000 (Blitz Beat "every 20 AGI +1%"); `T_AXadd0_etc_withlimit` the same with the attribute capped at the last value (the "Resonance 0.1%" skills: Jack Frost and the other Warlock spells DEX, Arrow Storm AGI, Axe Tornado and Earth Drive VIT, Sonic Burst and Arm Cannon LUK, Radiant Holy Light's heal DEX; the cap of 100 is read as attribute points, inferred); `AXaddBplus1(_withlimit)` [A, 115, B, limit] = (B + A x ASPD) / 10000 with the panel ASPD (attribute 115, 100 = 100%) capped at 500 (Cross Ripper Slasher "x (1 + ASPD x 0.12%)", Banishing Thrust, Rift Impact, Heavy Cannon Shot, Rolling Cutter, the Shadow skills); `T_AXadd0_Xisskilllv` is Heal's "+0.1% per Base Level", on heals only. Mode 3 tuples are flat amounts (shields) and `AXadd_HitCount_ExtraDmg` is in no description, so neither multiplies. Physical rows described as MATK-based use MATK (Magic Crasher, Double Holy Light's physical hit JudexMix1), and Soul Destroyer uses PATK + MATK. A `_kDamageParam1/2` branch is picked per target: Heal [1] on enemies, Holy Cross [1] with a two-handed spear, Soul Strike [1] on Undead (element or race, inferred), Magnus Exorcismus [1] on Undead or Demon race, Shield Press/Earth Drive/Powerful and Ultra Shield Bash [1] on monsters, Sonic Blow [1] at or below 50% HP (`_kLogicData` [2000, 101, 5000]) or [2] at or below 80% with Supersonic Blow. Prey on the Weak adds its buff's `_kLogicData` bp against a target with a live debuff (`_iType` 2). Skills that land in parts send one 31101 per part, spread from the first attack point to the last (inferred timing): Soul Expansion one per entry; Tetra Vortex Water/Fire/Earth/Wind, each rolling its own status (Frozen/Burn/Petrify/Stun) and the last `_kBuff2` tuple (Frozen 100%) on a target none reached; Gravitational Impact `_kShowDmg` [3, 1] hits of each entry; Axe Tornado's spins of [0] then [1] (the spin count from the described total: 6, or 10 Enhanced); Piercing Shadow's two slashes; Myriad Stars one 200% arrow per attack point. Single-target rows that hit more: a row with `_kRange` and `_iTargetMax` > 1 hits that area (around the locked target for release 1/7/8, target first: Virus Spread; around the caster: Evil Spirit Threat, Rolling Cutter); Blitz Beat `_kLogicData` [300, 3] adds up to 2 enemies within 3 m of the target; Sharp Shooting [3, 150] and Focused Arrow Strike (`_kDescData` 5, width 1.5 m inferred) hit a line from the caster through the target as long as the skill's range; Envenomed Blade's blade jumps up to 3 times (`_kLogicData` [4]) to a random enemy not yet hit within 3 m of the last one, 200 ms apart (inferred). Not yet: Gravitation Field and Magnus Exorcismus/Sanctuary as fields, Arm Cannon's shell spread, the talent extra casts, Steal's Hiding branch.

**Class resources** (`CombatService.Resources`). `_kSkillCostParam` is only the client's meter display; the meters are EnergyConfig rows (31334) that the server fills, spends and converts from the descriptions (inferred where noted). Cross Ripper Slasher throws every blade of 540002 (starts at 4, no refill by itself): damage x max(1, blades), the meter empties, and a throw with 4 blades (`_kDescData[4]`) ends its own cooldown with the hit. Rolling Cutter adds `_kDescData[5]` = 1 blade per cast up to `[6]` = 4 (inferred: whether or not it hits). Reading Spellbook's 【Reading】 (1231001, `_kBuff1` duration -1) lasts until Stop Reading (its mode 4) or death, with no countdown; while it is on, a spellbook skill whose `_kSkillHighParam` names it (`"0:1231001:1&2:240001:N"`, or the older `"1231001:1&1233501:N"` read as pages) spends N pages of 240001 and casts its `_kAutoLearnSkill[0]` copy at the same level and target 500 ms later (the length of the "Spellbook - ..." mark it grants; inferred timing): Jack Frost, Earth Strain, Crimson Rock and Thunderclap 3 pages, Comet, Tetra Vortex and Gravitational Impact 5, Soul Expansion 1. Precision Thrust's 140001 (+1 per hit) turns 6 into one Hundred Spears charge (140002); Sonic Burst's Furious Storm (lasting) sets the enhanced charges 140003 to 5 and ends when they are spent (inferred). Shield Bash's 141002 (+1 per hit) turns 20 into 3 piles of 【Enhance Shield Bash】 1163101, which switches Shield Bash to its enhanced form; each enhanced cast spends a pile (inferred).

**Stealth** (`BuffService.Stealth`). A live `_kBuffCategory` 31 buff hides the player: attribute 3010 (`enum_unitAttrMap.Stealth`, which `LC_UnitStealthManager` hides from viewers without 3011/3012) is 1, monsters do not pick, engage or keep chasing them, except bosses and the Insect and Demon races (classic RO, inferred). The buff's `_kLogicData` [id, reveal on dealing damage, hits] ends it: Disguise [15007, 1, 1-3], Enhance Cloaking [15305, 1, 5], Hiding [50031, 0, 1]; a row without it breaks on the first hit or damage. The buffs cast with it that share its id (Disguise's 【Hiding】 speed buff) end with it. Not yet: revealing hidden enemies (Sight, Ruwach, Earth Strain), since no monster hides yet.

**Companions** (`CombatService.Companions`). The falcon, the Demonic Wolf and the Madogear are Special Class Item leases (CareerSpecialService); the wolf and the Madogear are also battle mounts (5012 slot 2). Each skill row's `_iSkillCondition` names an `LC_ConditionList` row the server now checks before a cast (error 3018), as the client's `LC_InteractCondition` reads it: `[2001, subtype]` a worn equipment item of that subtype (2002 none), `[2003, id]` riding that battle mount (2004 not), `[2006, type]` a pendant of that PendantConfig `_iType` (1 falcon, 2 cart, 6 wolf; 2007 none); `m_eType` 1 is all clauses, 2 any. So Blitz Beat and Detecting need the falcon, the Warg skills the wolf ride, Arm Cannon and the other Madogear skills the Madogear, Dragon Breath the dragon, and spear, shield, bow, katar and dagger skills their weapon. The normal attack follows `JobAttackConfig._iMountID` like `Lua_CFG_JobAttackConfig._getData`: Warg Strike 1003201 on the wolf, Normal Punch 1631001 in the Madogear, 1100001 on the dragon, and 5025 is resent when the ride changes. A leased pendant's `_iPendantBuffID` (Falconry, Warg Accessory) lasts while it is leased and a ridden mount's `_kBindBuff` (the wolf's Wolf Taming 1331001: +10% move speed and Warg Charge) while it is ridden, re-applied after a scene change; Wolf's Fang adds its `_kLogicData` buff while on the wolf. The following wolf howls (Warg Howl's 1332501, PATK +5% for 10 s) on the first damage dealt every 30 s (inferred: while fighting). Warg Bite resets Warg Hunt's cooldown, Warg Charge and Warg Hunt reset Swift Warg's, and under King of the Wargs Warg Charge sends 4 companion hits (row 1332705, 80% each) and Warg Bite one 240% companion hit (1332805) (inferred split). Not yet: Warg Hunt's melee/ranged sub-rows and dash (the main row's damage applies), Swift Warg's cast-on-next-move, and Detecting's reveal.

The live DAL's zero-based plan indexing and UI-position-minus-one conversions come from `LC_DAL_SkillDevelop.lua:1095-1136` and `LC_SkillDevelopServer.lua:115-219,244-306`. Plan count reads `PublicParamConfig.SchemeNum` (5 in the current export); the first new account receives that many unlocked plans **(inferred local entitlement policy)**. The separate `SkillSchemeNum` and `SkillSchemeCD` constants are not used for this live plan path. Switch cooldown reads generic `SchemeCD` (3 seconds in the current export) and is session-local **(inferred server policy)**. Valid unlocked plan indices are persisted, so future entitlement changes can change the saved flags without changing the wire model.

The reset request clears paid allocations in its selected plan and prunes unloaded skills without an item charge **(inferred policy)**; the client UI reset instead commits target levels through 31151. Name length reads `SchemeNameNumMax`. A nonnegative genre value is accepted; the exact original genre enumeration is unverified. Queue length reads `QueueNum`; queue load checks learned level and `SkillConfig._iQueue=1` by default. The client also checks `LC_DynamicParamMgr.GetDynamicSkillCanBeQueue` in `Lua_CFG_SkillConfig.lua:2100-2148`; `QueueEligibility` is an integration callback for the combat-owned dynamic rule. Invalid indices, unknown/unlearned groups, insufficient rank points, dependencies and combat-time bar/queue/switch/reset requests return a nonzero `ErrorCodes` value without changing durable state. The client sends `socketNum` and `queueIndex` zero-based; wheel keys are 1-based, queue keys remain zero-based. Manual and auto lists retain selected skill levels; 5025 wheel rows use those levels.

The empty queue entry `{0:SkillData{}}` and empty load-list entry are **(inferred compatibility sentinels)** for the client Lua readers of those lists. Neither creates a learned skill. On relog, the persisted plans are loaded before 5025. Legacy `skills` and `skill_bar` columns seed plan 0 once; later saves keep them as the active projection. Runtime evidence is the focused wire tests in `SkillGrowthTests.cs`; original-server entitlement, genre limits, fee, cooldown persistence and client visual behavior remain unverified.
